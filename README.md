# fribot 
a robot with two wheels. show case of balancing, remote control, obstacle avoidance and etc.


# stack

- 18650 Li-ion battery - 3.7V, 3100 mAh, XH2.54 connector
- motor driver TC1508A
- esp32 dev board (ESP-IDF v6.1)
- 2x motors N20 3V 300rpm
- electrolytic capacitor 25V-1000mkF 
- a switch 
- MPU6050
- charger 1865 TP4056

for remote controller: 
- TFT-display 0,96/1,3"
- joystick KY-023 XY
- esp32 dev board
